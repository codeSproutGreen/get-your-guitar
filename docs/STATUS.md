## 다음 할 일

1. **클라이언트 피드백 대기:** v1.1.0의 음색(폰 스피커/이어폰), 뮤트 바를 누른 채 연주하는 느낌, 레이크/벤딩 구분(설정의 "레이크" 슬라이더로 직접 조정 가능), 해머온·풀오프. `docs/verification-checklist.md`의 사람 항목.
2. 기본값 후보: 폰에 맞춰져 있던 값이 볼륨 100 · 밝기 71 · 감쇠 100 · 벤딩 2음 · 버퍼 16 ms였다. 클라이언트가 계속 이 값을 쓰면 앱 기본값으로 삼는다.
3. 음색이 아직 부족하다는 피드백이면: `VoiceCharacter` 조정 → 그래도 안 되면 샘플 음원(v2 문서 1-2절 B안).
4. 보류 중(사용자 결정): 메트로놈, 5현/튜닝, 녹음/재생. (실제 프렛 간격은 2026-09-21에 구현, 미릴리스)
5. **아키랩 pull 후:** 프리앰블 붙여 `./gradlew.bat :core:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug`. JDK 17 빌드와 `platforms;android-37` 자동 다운로드는 아직 아키랩에서 확인된 적 없다. 릴리스는 서명 때문에 SDS PC에서만 만든다.
