# 실기기 검증 체크리스트

스펙 8.3. 검증 환경에서만 채운다. 아키랩에서는 어떤 항목도 "확인됨"으로 표기하지 않는다.
결과는 날짜·기기·빌드 커밋과 함께 아래 표에 적어 push한다.

- 상태 표기: ✅ 통과 / ❌ 실패(메모에 증상) / ⬜ 미확인 / ➖ 해당 마일스톤 아님
- **확인 방법** 열의 `adb` = 터치 주입·로그·스크린샷으로 기계적으로 확인 가능, `사람` = 손과 귀가 필요.

## 기기

| 기기 | OS | 오디오 경로 |
|---|---|---|
| Galaxy S10e (SM-G970N), 테스트용 | Android 12 / API 31 | 48 kHz, 버스트 192프레임, FAST 트랙(F3), 실효 버퍼 384프레임, AudioFlinger 보고 지연 16 ms |
