# M0 스캐폴드 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `:core`(순수 Kotlin/JVM) + `:app`(Android/Compose) 두 모듈이 아키랩에서 빌드·테스트되고, "get-your-guitar" 텍스트만 띄우는 빈 앱 APK가 나온다.

**Architecture:** Gradle 멀티모듈. `:core`는 `kotlin("jvm")`만 쓰는 라이브러리(Android 의존 0, JUnit Platform으로 테스트), `:app`은 AGP 9의 **built-in Kotlin**(별도 `kotlin-android` 플러그인 없음) + Compose 컴파일러 플러그인. 버전은 전부 `gradle/libs.versions.toml`에 고정. 이 마일스톤엔 앱 로직이 없다 — 파이프라인이 도는지만 확인한다.

**Tech Stack:** Gradle 9.7.0 (wrapper), AGP 9.4.0, Kotlin 2.4.20, Compose BOM 2026.09.00 (ui 1.12.1 / material3 1.4.0), JUnit Jupiter 6.1.3 (JUnit 5 API), JDK 17 (Temurin 17.0.20.1)

**Spec:** `docs/superpowers/specs/2026-09-16-get-your-guitar-v1-design.md` — 9장 "M0 — 스캐폴드", 10장 "스택·환경"

## Global Constraints

- minSdk 33 / compileSdk 36 / targetSdk 36 (스펙 2장·10장). JDK 17 (스펙 10장, AGP 9.4 최소 요구).
- 패키지·namespace·applicationId: `com.sproutgreen.getyourguitar`. `:core` 코드 패키지: `com.sproutgreen.getyourguitar.core`.
- 저장소엔 **코드만** 넣는다. JDK/SDK/Gradle 캐시는 커밋하지 않는다 (CLAUDE.md). `local.properties`는 gitignore 되어 있다.
- 아키랩은 C: 드라이브 여유가 ~1 GB → Gradle 배포판·캐시는 반드시 `GRADLE_USER_HOME=E:\yjane.kim\tools\gradle-user-home` 로 간다 (README "아키랩" 절).
- **아키랩의 Claude Code Bash 세션에는 환경변수가 안 들어와 있다.** 모든 Gradle 명령 앞에 아래 프리앰블을 붙인다. (`gradlew.bat`을 쓴다 — `.bat`은 `JAVA_HOME`을 우선 사용하므로 시스템 PATH의 JRE 1.8을 타지 않는다.)
  ```bash
  export JAVA_HOME='E:\yjane.kim\tools\jdk-17.0.20.1+1' GRADLE_USER_HOME='E:\yjane.kim\tools\gradle-user-home'
  cd /e/yjane.kim/project/get-your-guitar
  ```
- AGP 9.x built-in Kotlin: `:app`에 `org.jetbrains.kotlin.android`를 **적용하지 않는다**(적용하면 "no longer required since AGP 9.0" 에러). `jvmTarget`은 `compileOptions.targetCompatibility`를 따르므로 따로 안 잡는다.
- 알려진 버전 경계: KGP 2.4.20의 공식 지원 범위는 Gradle ≤ 9.7.0, AGP ≤ 9.3.1. AGP 9.4.0은 그보다 한 단계 위이고 자체적으로 KGP 2.2.10을 번들한다. 루트 플러그인 블록에 KGP 2.4.20을 올리면 클래스패스에서 2.4.20이 이겨 전체 빌드가 2.4.20을 쓴다. Task 1 Step 6에서 이 조합이 실제로 동작하는지 검증하고, 실패 시 대응이 적혀 있다.
- 커밋은 작업 단위마다. 기기 동작은 아키랩에서 확인할 수 없으므로 커밋 메시지·문서에 "검증 환경에서 확인 필요"로 표기한다.
- git 전역 identity(`codeSproutGreen`)가 설정돼 있으므로 `git commit`을 그대로 쓴다. 커밋 메시지 끝에 `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` 줄을 붙인다.
